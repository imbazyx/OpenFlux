## Порядок публикации — важно

Подмодули обязаны уйти **раньше** форка. Форк записывает в индекс конкретные
коммиты подмодулей; если их не будет на GitHub, `git clone --recurse-submodules`
упадёт. Порядок:

1. `imbazyx/OpenFlux` ← ядро, коммит `5e714cd`
2. `imbazyx/OpenFluxClientShared` ← общий код, коммит `ba86d07`
3. `imbazyx/OpenFluxAndroid` ← форк, тег `v1.2.0`

## Что нужно сделать руками (однажды)

**Авторизация на GitHub.** SSH-ключ `~/.ssh/id_ed25519` есть, но на GitHub не
зарегистрирован: `ssh -T git@github.com` отвечает `Permission denied
(publickey)`. `gh` не установлен. Нужно одно из двух:

- добавить публичный ключ на <https://github.com/settings/ssh/keys>
  (тогда я сделаю всё остальное сам), или
- установить `gh` и выполнить `gh auth login` (тогда я смогу ещё и создать
  репозитории сам — через `git push` их создать нельзя).

- `dist/` (пять APK, >100 МБ) в `.gitignore`.

## Что нужно задать в репозитории перед релизом

GitHub → Settings → Secrets and variables → Actions:

| Имя | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | base64 от `.jks` |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | алиас ключа |
| `ANDROID_KEY_PASSWORD` | пароль ключа |

**Локальный keystore — личный.** Для публичных релизов нужен свой: иначе
любой, кто его получит, сможет подписать обновление вашего приложения.
