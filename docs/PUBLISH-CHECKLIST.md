- **Аккаунт: `imbazyx`.** Заглушки `REPLACE_WITH_GITHUB_ACCOUNT` заменены в
  `README.md` и `AndroidPlatformServices.kt` (`RELEASE_REPO`).
- **Версия: 1.2.1** — совпадает с APK, собранным и подписанным из этого
  дерева (`versionCode` 10201). Не 2.0.0 из старого CHANGELOG.
- **Один репозиторий.** `OpenFlux/` и `shared/` — обычные каталоги, не

  конкретный коммит ломался дважды за сессию, и оба раза это обнаруживалось
  только при отклонении пуша.

## Состояние на GitHub

Всё живёт в одном репозитории — [imbazyx/OpenFlux](https://github.com/imbazyx/OpenFlux),
под именем самого проекта, а не приложения.

| Репозиторий | Состояние | Роль |
|---|---|---|
| `imbazyx/OpenFlux` | **главный** | весь проект одним деревом: приложение, ядро, общий код |
| `imbazyx/OpenFluxAndroid` | будет удалён | бывший комбайн, перенесён сюда |
| `imbazyx/OpenFluxClientShared` | будет удалён | бывший дубликат общего кода |
| `imbazyx/OpenFlux`, ветка `core` | есть | прежняя история ядра (170 коммитов, теги `0.0.1`…`v0.1.0`) |

Клонируется одной командой, без `--recurse-submodules`, и сразу собирается:

```bash
git clone https://github.com/imbazyx/OpenFlux.git
```

Старые теги ядра (`0.0.1`…`0.0.5`, `v0.1.0`, `node-v1.0.0`) оставлены и
указывают на историю, которой больше нет ни в одной другой копии. Релиз
приложения — `v1.2.1`.

## Что нужно сделать руками (один раз)

**Секреты для Actions.** GitHub → Settings → Secrets and variables → Actions:

| Имя | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | base64 от `.jks` |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | алиас ключа |
| `ANDROID_KEY_PASSWORD` | пароль ключа |

Без них релизный workflow не сможет подписать APK. `gh auth login` больше не
нужен: репозитории созданы, отправка идёт по SSH-ключу.

**Локальный keystore — личный.** Для публичных релизов нужен свой: иначе любой,
кто его получит, сможет подписать обновление вашего приложения, и пользователи
это установят. Потеря ключа навсегда блокирует обновление уже установленного
приложения.

## Секреты — проверено, утечек нет

- Пароли keystore читаются из переменных окружения (`ANDROID_KEYSTORE_PASSWORD`,
  `ANDROID_KEY_PASSWORD`), в коде их нет.
- Keystore вне репозитория: `$HOME/build/openflux-release.jks`, пароль в
  `$HOME/ofsign.env` (оба `chmod 600`). Сборка передаёт пароль через
  `-storepass:env` — вне списка процессов. Ни то, ни другое не попадает в
  индекс: аудит, который ищет утечки, не может пропустить собственный ключ.
- IP/хосты exit-нод и отпечатки сертификатов в индекс не попали.
- `dist/` (пять APK, >100 МБ) в `.gitignore`.

## Что проверено вживую, а что нет

- **Проверено на телефоне через LTE:** после 1.2.1 переход по ссылкам в
  браузере заработал. `asus.com`, который раньше висел (`tls=0.000`, 15 с),
  отвечает `200` за 0.53 с.
- **Проверено на сервере:** все четыре exit-ноды перезапущены на бинарнике,
  собранном из `f2855a7`; наличие новой логики подтверждено чтением
  `/proc/<pid>/exe`, а не номером версии.
- **Не проверено:** iOS (не прошли TestFlight), второй телефон на exit4.
- **Не проверено:** срабатывание переподключения на живом обрыве. Регрессия
  закрыта тестом, который красный без правки; сам обрыв на сервере не
  воспроизводился — рвать соединение на рабочих нодах рискованно.

## Починенная история

Первый коммит форка объявлял родителя, которого нет ни в одном репозитории: ни
в upstream, ни в 18 форках на GitHub, ни в reflog, ни в резервных копиях на
сервере. Клон был с обрезанной историей, и любой пуш падал с
`did not receive expected object`. Корнев��й коммит пересоздан с тем же деревом,
тем же автором и той же датой — без ссылки на несуществующий объект. Ни один
файл не изменился: дерево `96e6235` до и после.
