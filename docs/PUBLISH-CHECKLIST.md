После слияния подмодулей репозиторий стал дубликатом: те же исходники лежат
внутри `OpenFluxAndroid/shared/`. Он пустой и больше не используется. Удалить

## Что нужно сделать руками (один раз)

**Секреты для Actions.** GitHub → Settings → Secrets and variables → Actions:

| Имя | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | base64 от `.jks` |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | алиас ключа |
| `ANDROID_KEY_PASSWORD` | пароль ключа |

Без них релизный workflow не сможет подписать APK. `gh auth login` больше не
нужен: репозитории созданы, отправка идёт по SSH-ключу.

**Локальный keystore — личный.** Для публичных релизов нужен свой: иначе любой,
кто его получит, сможет подписать обновление вашего приложения, и пользователи
это установят. Потеря ключа навсегда блокирует обновление уже установленного
приложения.

## Секреты — проверено, утечек нет

- Пароли keystore читаются из переменных окружения (`ANDROID_KEYSTORE_PASSWORD`,
  `ANDROID_KEY_PASSWORD`), в коде их нет.
- Keystore вне репозитория: `$HOME/build/openflux-release.jks`, пароль в
  `$HOME/ofsign.env` (оба `chmod 600`). Сборка передаёт пароль через
  `-storepass:env` — вне списка процессов. Ни то, ни другое не попадает в
  индекс: аудит, который ищет утечки, не может пропустить собственный ключ.
- IP/хосты exit-нод и отпечатки сертификатов в индекс не попали.
- `dist/` (пять APK, >100 МБ) в `.gitignore`.

## Починенная история

Первый коммит форка объявлял родителя, которого нет ни в одном репозитории: ни
в upstream, ни в 18 форках на GitHub, ни в reflog, ни в резервных копиях на
сервере. Клон был с обрезанной историей, и любой пуш падал с
`did not receive expected object`. Корнев��й коммит пересоздан с тем же деревом,
тем же автором и той же датой — без ссылки на несуществующий объект. Ни один
файл не изменился: дерево `96e6235` до и после.
